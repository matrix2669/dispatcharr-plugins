# Dispatcharr Plugins

Third-party Dispatcharr plugin registry maintained by matrix2669.

## Add to Dispatcharr

Add this manifest URL under **Plugins → Plugin Repositories**:

```text
https://raw.githubusercontent.com/matrix2669/dispatcharr-plugins/main/manifest.json
```

Each plugin remains in its own source repository. This repository only contains the Dispatcharr registry manifest and per-plugin release metadata.
