# Dispatcharr VOD Newznab

Registry metadata for the Dispatcharr VOD Newznab plugin.

Source: `matrix2669/Dispatcharr-VOD-Newznab-Plugin`

The plugin exposes raw Xtream VOD variants to Sonarr/Radarr through Newznab Interactive Search, emulates the SABnzbd subset Servarr uses, and hands selected streams to Mustarrd for acquisition.
