# FFmpeg Smart Profiles

Registry metadata for the Dispatcharr FFmpeg Smart Profiles plugin.

Source: `matrix2669/Dispatcharr-FFmpeg-Smart-Plugin`

The plugin creates configurable managed Stream and Output Profiles backed by its bundled hardware-aware FFmpeg wrapper. It supports explicit device overrides, active-job/capacity-based multi-GPU selection, hardware cache rebuilding, and real concurrent-stream capacity benchmarking from Dispatcharr's Plugins page.
